# Sistema Inteligente de Gestión de Inventarios y Prevención de Mermas en Cocinas Caseras


##Descripción del Proyecto
El mal manejo de insumos en cocinas domésticas genera pérdidas económicas por alimentos caducados o mal almacenados, además de la incertidumbre diaria sobre qué platillos preparar con lo disponible. 

Este sistema automatiza y centraliza la administración del inventario del hogar: registra insumos con fechas de caducidad, descuenta consumos de forma atómica y calcula instantáneamente qué recetas se pueden preparar (capacidades mínima, mediana y máxima) o qué compras se requieren según los platillos elegidos.
